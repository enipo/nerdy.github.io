Operating principles

Posted near the desk
House rules · v3

Boring tech, bold defaults, small surfaces.

  1. 01Read the code before writing the code.
  2. 02Boring tech for the load-bearing parts. Fun tech for the leaves.
  3. 03Observability is not optional. Logs are a love letter to future-you.
  4. 04Automate the second time. The first time, learn by hand.
  5. 05Small commits, clear messages, fewer surprises.
  6. 06Ship the smallest thing that proves the idea.

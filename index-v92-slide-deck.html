§ One slide if you're busy

If you only read one slide, read this one.

  • Software developer and infrastructure engineer. I build the boring backbone and the weird front of house.
  • Strongest where systems meet — distributed services, agents, automation, and the seams between them.
  • Currently shipping a terminal manager, a multiplayer tank game, and a productivity app I'm yet to name.
  • Run my own small fleet — multi-cluster Kubernetes, GitOps, observability, the lot.
"Make it boring on the inside so it can be playful on the outside." — operating principle

Years of experience: many. Production incidents survived: more. Side-projects abandoned: a healthy number. Self-rated bus factor: working on it.

§ Project · Nerdy Terminal

A keyboard-first terminal manager for the multi-agent era.

tm — multi-session

What it is

A macOS app that wraps tmux + a small CLI to coordinate humans and AI agents across many sessions — without leaving the keyboard.

Stack
Swift · Go CLI · tmux · sqlite
Scale
1 user (me) · 10+ concurrent sessions

Daily driver · own dogfood

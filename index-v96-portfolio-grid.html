CASE 01 / TOOLS 2024 — ACTIVE
Sole Author · macOS · Daily Driver
TypeScriptBuntmuxSQLiteClaude SDK
Featured Work · A Terminal You Don't Have to Apologise For

Nerdy Terminal — keyboard-first, multi-session, agent-aware.

A tab-based terminal manager with first-class support for multiple AI agents working in parallel — each in its own git worktree, talking to each other through a tiny CLI called tm. Three-tier hierarchy. No mouse needed.

Premise

Most "AI for developers" tools assume one human, one model, one window. Real work is messier — half a dozen branches, three clusters, two long-running tasks. Nerdy Terminal treats agents as first-class tabs and gives them a shared inbox.

Stack

  • TypeScript
  • Bun
  • tmux
  • SQLite
  • Anthropic SDK
  • git worktrees
  • Web UI (React)

Highlights

Zero-mouse session creation · Activity feed across every agent · Approval routing for risky commands · Dashboard with peek/inbox/learn primitives · Worktree-aware: each agent on its own branch.

CASE 03 / AI 2025
Lead · Production gateway · Code-mode tools
GoMCPPostgresOAuth
Bridge · Agents ↔ Reality

MCP Gateway

One auth boundary, dozens of tools — Slack, Jira, Postgres, Grafana, Tailscale — exposed to AI agents through a single Model Context Protocol surface.

Why

Giving every agent direct access to twelve different APIs is a security mess. The gateway centralises auth, audit, rate-limits and lets tools be called as code rather than shouted as JSON.

Stack

  • Go
  • MCP
  • Postgres
  • OAuth 2
  • JS sandbox
